# UI/UX Polish & Animation Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modernize spacing, shadows, hover/focus states, and add Framer Motion animations across every page while keeping all functionality, branding, and colors byte-identical.

**Architecture:** CSS-first polish inside each route's existing co-located CSS file, plus a small reusable motion-wrapper layer (`components/motion/`) built on framer-motion's LazyMotion. Pages gain only classNames and presentational wrappers — no logic edits.

**Tech Stack:** Next.js 16 App Router, React 19, framer-motion (new dep, LazyMotion + `m.*`), custom CSS with tokens in `app/globals.css`.

## Global Constraints

- **NO GIT COMMITS.** The user commits manually after reviewing each task. At the end of each task, STOP and report what changed; never run `git add`/`git commit`.
- Spec: `docs/superpowers/specs/2026-07-07-ui-polish-design.md` — read it before starting any task.
- Never modify: handlers, hooks, effects, API calls, conditional logic, routing, copy text, or any file under `app/api/`, `services/`, `hooks/`, `lib/`.
- Existing color tokens and gradients stay byte-identical: `--navy: #1a1f36`, `--blue-start: #1a4fd4`, `--green-end: #0f9b4f`, `--lime: #c8e64a`, `--gradient-hero`, `--gradient-cta`.
- Animate only `transform` and `opacity` (60fps); every animation respects reduced motion (global CSS kill switch + `useReducedMotion` in components).
- JS files use `.js` extension, `"use client"` where hooks are used, path alias `@/*` available.
- Verify cycle per task: `npm run build` exits 0, then visual check in `npm run dev`.
- **Polish Vocabulary** (referenced by page tasks; tokens defined in Task 1):
  - Card at rest: `border-radius` from radius scale; `box-shadow: var(--shadow-sm)`; `transition: transform var(--dur-med) var(--ease-out-soft), box-shadow var(--dur-med) var(--ease-out-soft), border-color var(--dur-med) var(--ease-out-soft);`
  - Card hover: `transform: translateY(-3px); box-shadow: var(--shadow-md); border-color: var(--icon-blue);`
  - Button press (all buttons): `.some-btn:active { transform: scale(0.98); }`
  - Input focus: `border-color: var(--blue-start); box-shadow: var(--focus-ring);`
  - Modal overlay: `animation: overlayIn var(--dur-fast) var(--ease-out-soft);` panel: `animation: panelIn var(--dur-med) var(--ease-out-soft);` (keyframes defined in Task 1)
  - Inline banner (success/error): `animation: bannerIn var(--dur-med) var(--ease-out-soft);`
  - Skeleton: markup `<div className="skeleton" style={{height: …}} />` rendered under the **same condition** that previously rendered "Loading…" text/spinner.

```js
"use client";

import { m, useReducedMotion } from "framer-motion";

const parent = {
  hidden: {},
  show: { transition: { staggerChildren: 0.05 } },
};

const child = {
  hidden: { opacity: 0, y: 12 },
  show: { opacity: 1, y: 0, transition: { duration: 0.4, ease: [0.22, 1, 0.36, 1] } },
};

export function Stagger({ children, className }) {
  const reduce = useReducedMotion();
  if (reduce) return <div className={className}>{children}</div>;
  return (
    <m.div
      className={className}
      variants={parent}
      initial="hidden"
      whileInView="show"
      viewport={{ once: true, margin: "-40px" }}
    >
      {children}
    </m.div>
  );
}

export function StaggerItem({ children, className }) {
  const reduce = useReducedMotion();
  if (reduce) return <div className={className}>{children}</div>;
  return (
    <m.div className={className} variants={child}>
      {children}
    </m.div>
  );
}
```

- [ ] **Step 5: Create `components/motion/AnimatedNumber.js`**

```js
"use client";

import { useEffect, useRef } from "react";
import { animate, useReducedMotion } from "framer-motion";

export default function AnimatedNumber({ value, format = (n) => n.toLocaleString("en-IN") }) {
  const ref = useRef(null);
  const prev = useRef(value);
  const reduce = useReducedMotion();

  useEffect(() => {
    if (!ref.current) return;
    if (reduce) {
      ref.current.textContent = format(value);
      prev.current = value;
      return;
    }
    const controls = animate(prev.current, value, {
      duration: 0.5,
      ease: [0.22, 1, 0.36, 1],
      onUpdate: (v) => {
        if (ref.current) ref.current.textContent = format(v);
      },
    });
    prev.current = value;
    return () => controls.stop();
  }, [value, reduce, format]);

  return <span ref={ref}>{format(value)}</span>;
}
```
